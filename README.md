# Satellite-Based Ground Deformation Analysis

This project applies **satellite data processing (InSAR)** and **geospatial analytics** to monitor and analyze **ground displacement and subsidence**.  
It integrates multiple datasets — including **ascending/descending orbits**, **EGMS**, **Copernicus**, and **environmental variables** — to understand spatial deformation dynamics.

---

## Project Summary

- Processing of **satellite interferometric data** to extract **vertical (dV)** and **horizontal (dH)** displacements.  
- **Spatial and temporal analysis** using clustering, trend detection, and STL decomposition.  
- Integration with **temperature, precipitation, and reservoir levels** to assess environmental drivers of ground movement.  
- Quantitative validation using **RMSE** and **MAE** metrics for accuracy assessment.
